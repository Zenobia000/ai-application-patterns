# Patterns：六種底層方法

| Pattern | 結構 | 暖身題（30 分鐘） | 主要 Lab |
|---|---|---|---|
| [P1 Generate](generative-media/) | Prompt → Model → Artifact | 幫自己做一張 LINE 貼圖組 | Lab 03、05 |
| [P2 Retrieve & Reason](knowledge-reasoning/) | Context → LLM → Answer | 問你的課程大綱 | Lab 01、02 |
| [P3 Code & Build](coding-agent/) | Requirement → Agent → Code → Runtime | 做一個「今天吃什麼」轉盤 | Lab 04、05 |
| [P4 Tool Use](tool-use-mcp/) | Agent → API/MCP → Tool | 讓 AI 幫你整理下載資料夾 | Lab 02、06 |
| [P5 Workflow Orchestration](workflow-agent/) | Trigger → Agent/Rules → Tools | 每天早上的天氣穿搭提醒 | Lab 07 |
| [P6 Observe–Act Loop](computer-use/) | State → Reason → Action → Verify | 讓 Agent 幫你查圖書館有沒有這本書 | Lab 06、08 |

每個 Pattern 文件包含：結構、適合與不適合的問題、常見失敗模式、驗證方法、暖身題、延伸閱讀。

完整比較見 [taxonomy/method-characteristics.md](../taxonomy/method-characteristics.md)。
