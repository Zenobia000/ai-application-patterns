# P1 Generate：生成媒體

```text
Prompt（+ 參考圖 / 參考音訊）→ 生成模型 → Artifact（圖、影片、音訊、3D）
```

## 1. 它在做什麼

用模型「創造」原本不存在的內容。核心能力是從描述或參考素材，產出視覺、影音、聲音或 3D 資產。

2026 年的重要轉變：生成能力不再只存在於網頁介面，而是被包成 **工具**（API、MCP），讓 Agent 在更大的流程裡呼叫。例如 Higgsfield 提供官方 MCP，Claude 可直接呼叫 30 多種影像與影片模型；ComfyUI 把影像、影片、音訊、3D 都抽象成可重用的節點圖，並提供 Server API。

## 2. 適合 / 不適合

| 適合 | 不適合 |
|---|---|
| 主視覺、插圖、概念圖 | 需要精確文字的畫面（價格、地址）→ 用後製疊字 |
| 短影音、廣告素材 | 需要與真實商品 100% 一致 → 用真實照片當參考或直接拍 |
| 配音、音效、背景音樂 | 需要可重現的結果（同輸入同輸出） |
| 大量變體（A/B 測試） | 法律上需要真實性的內容（證據、新聞） |

## 3. 常見失敗模式

| 失敗 | 原因 | 對策 |
|---|---|---|
| 角色/商品前後不一致 | 每次生成都是獨立抽樣 | 參考圖、角色鎖定功能、固定 seed |
| 畫面中文字錯亂 | 模型不擅長文字 | 不要在生成中放字，後製加字幕 |
| 風格漂移 | prompt 每次寫法不同 | 固定一段「風格描述」附在每個 prompt 後 |
| 好看但不對題 | 缺乏具體 brief | 先寫分鏡表，再逐鏡生成 |

## 4. 驗證方法

生成媒體是 **人工驗收成本最高** 的 Pattern。業界做法：

1. **一次產多版，人只負責挑**（例如每鏡 3–4 版）
2. **盲測**：拿給沒參與的人看，問「這是什麼店？」「想不想去？」
3. **檢查清單**：品牌色、商品外觀、字幕錯字、時長、比例
4. **記錄採用率**：生成 N 次、採用 M 次，這個比例就是你的真實成本

## 5. 暖身題：幫自己做一組 LINE 貼圖（30 分鐘）

> 用一張自己（或寵物）的照片當參考，生成 8 張同一角色、不同表情的貼圖：「收到」「好累」「期末加油」「哈哈」「謝謝」「？」「晚安」「讚」。

**你會遇到的問題**：第 5 張開始角色長得不一樣了。這就是「參考一致性」問題，也是影片生成最大的難題。

**驗收**：8 張放在一起，朋友能一眼看出是同一個角色。記錄你總共生成了幾張才湊齊 8 張。
