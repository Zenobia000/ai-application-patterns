# 工作坊導讀：為什麼做這件事？價值在哪？

> 給講師、帶隊學長姐，以及第一次來的學員。

---

## 1. 我們想解決的問題

AI 工具每週都有新的。多數人的學習方式是：

> 看到一支爆紅影片 → 註冊那個工具 → 玩兩下 → 下週又換一個。

結果是 **帳號很多，但遇到自己的問題時，還是不知道該用什麼、怎麼組合**。

這個工作坊反過來做：

> 先選一個生活中看得懂的問題 → 拆解它的特性 → 選 Pattern → 才去挑工具 → 做出能用的成果 → 回頭寫下「為什麼這樣選」。

工具會過時，**拆問題的能力不會**。

---

## 2. 為什麼題目都這麼「日常」？

你會發現題目是咖啡店、社團招生、宿舍房間、期末考，不是「企業級知識管理平台」或「工業數位孿生」。這是刻意的：

| 理由 | 說明 |
|---|---|
| **每個人都是領域專家** | 你知道宿舍長什麼樣、社團招生最煩什麼。不需要先學產業知識，就能判斷 AI 做得好不好。 |
| **驗收標準人人懂** | 「這支廣告會不會想去買？」「這個回答跟學生手冊一樣嗎？」不需要專家也能評分。 |
| **結構與真實產業相同** | 咖啡店 AI 店員 = 電商客服的縮小版；宿舍 3D 佈置 = 室內設計/建築視覺化的縮小版；每週情報站 = 企業情報監控的縮小版。 |
| **做完能馬上用** | 社團真的可以用這個網站招生，小店老闆真的可以用這支影片。 |

每個 Lab 的開頭都有一段 **「放大到真實世界」**，說明這個小題目在產業裡對應什麼工作。學員要知道自己練的不是玩具，是縮小比例的真實系統。

---

## 3. 學員會得到什麼

1. **一個可展示的作品**：每個 Lab 都要交付可以給別人看的東西（網址、影片、GLB 檔、Bot）。
2. **一份拆解筆記**：用 [問題特性表](../taxonomy/problem-characteristics.md) 分析自己的題目，寫下選擇理由。
3. **一次和 Agent 協作的經驗**：學會怎麼給 Agent 任務、怎麼驗收、什麼時候該接手。
4. **對 AI 能力邊界的真實感受**：哪些事 AI 一次就做好，哪些事要改十次，哪些事最後還是人做比較快。這個感受比任何教學影片都寶貴。

---

## 4. 我們（研究者）得到什麼

這個工作坊同時是一個研究計畫。每位學員的實作是一筆資料：

- 哪一種 Pattern 在學生手上成功率最高？
- 哪一個步驟最容易卡住？（我們猜：驗收、以及工具安裝）
- 同一個題目，不同人選了不同工具，結果差多少？
- 「人工驗收成本」實際上是多少分鐘？

請學員在交件時填寫每個 Lab 最後的 **實作紀錄表**。這些紀錄會回饋到 `taxonomy/` 的分析表，讓它從「推論」變成「觀察」。

## 5. 建議帶法

### 單次工作坊（3 小時）

| 時間 | 內容 |
|---|---|
| 0:00–0:30 | 講解三件事：七大類、六種 Pattern、問題特性表 |
| 0:30–0:45 | 分組、選 Lab（每組 2–3 人） |
| 0:45–2:30 | 實作（講師巡場，優先處理環境問題） |
| 2:30–3:00 | 每組 3 分鐘展示：成果 + 「最意外的一件事」 |

建議單次工作坊選 **Lab 01、03、04、07**：安裝門檻最低。

### 系列工作坊（10–11 週）

| 週 | 主題 |
|---|---|
| 1 | 分類法 + Lab 01（知識問答） |
| 2 | Lab 04（網站）— 認識 Coding Agent |
| 3 | Lab 03（短影音）— 認識生成媒體與驗收成本 |
| 4 | Lab 02（AI 店員）— 對話與工具呼叫 |
| 5 | Lab 07（自動化）— 把 AI 塞進流程 |
| 6 | Lab 06（3D）或 Lab 08（電腦操作）— 觀察→行動迴圈；要走複合管線的請選 Lab 06 |
| 7 | 複合管線導論：[composite-pipelines.md](../taxonomy/composite-pipelines.md) + Lab 10（AI 剪輯） |
| 8 | Lab 09（圖 → 3D → 遊戲） |
| 9 | Lab 11（Blender 預演 → AI 影片），可接續 Lab 09 的吉祥物 |
| 10–11 | Capstone：組合 Pattern 做完整專案 |

## 7. 共通規則

1. **Agent 做事前你要先說清楚「怎樣算完成」**。每個 Lab 都有「驗收標準」，先抄進你給 Agent 的任務裡。
2. **不要把個資、帳號密碼貼給 AI**。Lab 02、07、08 會碰到外部帳號，一律用測試帳號。
3. **尊重網站規則**。Lab 08 只抓公開頁面，遵守 robots.txt，不做大量請求。
4. **生成素材要標示**。Lab 03、05 的 AI 生成內容對外發布時請註明。
5. **失敗也要記錄**。卡住的地方是最有價值的研究資料。
